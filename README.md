# Advanced Fabrics Specifications

This repository contains normative specifications and Advanced Fabrics Enhancement Proposals (AFEPs). Implementations may vary internally, but a conformant implementation must satisfy the stable contracts and conformance assertions published here.

- `afeps/0000-process.md` defines the proposal process.
- `compatibility.md` defines versioning and deprecation guarantees.
- API source files live in `advanced-fabrics/api`; released copies are rendered at https://spec.advfab.org.

Advanced Fabrics is not a CNCF project and does not claim CNCF endorsement.
